A Hybrid Approach to Document Question Answering Using Transformer-Based Retrieval

Abstract

Large documents contain valuable information, but conventional keyword search
forces users to manually locate and interpret relevant passages. This paper
proposes a hybrid retrieval-augmented question answering system that combines
lexical (BM25) and dense semantic retrieval to improve answer grounding in
long-form documents. We evaluate our approach against a purely lexical
baseline and a purely semantic baseline using a custom evaluation dataset of
120 questions drawn from academic and regulatory documents.

Introduction

Traditional document search relies on exact keyword matches, which frequently
fails when a user's query uses different vocabulary than the source document.
For example, a student searching for "students who are not eligible for the
final exam" may miss a passage that discusses "minimum attendance requirements
for examination eligibility," even though the two describe the same concept.

Semantic retrieval, powered by dense vector embeddings, addresses this gap by
matching queries and passages based on meaning rather than surface form.
However, semantic retrieval alone can sometimes miss passages that share exact
terminology but diverge slightly in meaning, which is where lexical methods
such as BM25 remain valuable.

This paper investigates whether combining both approaches, a method we refer
to as hybrid retrieval, produces measurably better question answering results
than either method in isolation.

Related Work

Retrieval-augmented generation (RAG) systems typically use a single retrieval
strategy, most commonly dense embeddings computed via a pretrained sentence
transformer model. BM25 remains a strong baseline in information retrieval
research due to its interpretability and low computational cost. Prior work
combining lexical and semantic signals has shown promising results in web
search but has been less thoroughly evaluated for long-form document question
answering specifically.

Methodology

The proposed system combines supervised classification with transformer-based
feature extraction. Documents are first split into overlapping chunks of
approximately 220 words, preserving page and section metadata for later
citation. Each chunk is embedded using a sentence-transformer model producing
384-dimensional vectors, which are indexed using a FAISS flat index for exact
nearest-neighbor search.

In parallel, an Okapi BM25 index is built over the same chunks using standard
tokenization. At query time, both indices are queried independently. Semantic
scores and BM25 scores are each normalized to a zero-to-one range, then
combined using a weighted sum with weights of 0.6 for semantic similarity and
0.4 for lexical relevance. The top-ranked chunks are passed to a large
language model along with the user's question, with an explicit instruction
to answer only from the provided passages and to state clearly when the
passages do not contain sufficient information.

Dataset

We constructed an evaluation dataset of 120 question-answer pairs manually
verified against five source documents: two academic papers, two university
regulation documents, and one technical manual. Each question was labeled
with the specific page containing the supporting evidence, enabling precise
retrieval evaluation using Precision@5, Recall@5, and Mean Reciprocal Rank.

Results

The hybrid retrieval method achieved a Precision@5 of 0.83 and a Recall@5 of
0.91, outperforming the semantic-only baseline (Precision@5 of 0.76) and the
BM25-only baseline (Precision@5 of 0.68). Mean Reciprocal Rank followed a
similar pattern, with hybrid retrieval scoring 0.89 compared to 0.81 for
semantic-only and 0.71 for BM25-only retrieval.

For question answering quality, answers generated using hybrid-retrieved
context achieved a token-level F1 score of 0.74 against human-written
reference answers, compared to 0.68 for semantic-only retrieval. Exact match
scores were lower across all methods, at 0.31 for hybrid retrieval, reflecting
the open-ended phrasing of many reference answers rather than a retrieval
failure specifically.

Limitations

The main limitation of this approach is its reliance on well-structured
source documents; scanned or image-only PDFs without extractable text require
a separate OCR pipeline not evaluated in this study. The model also struggles
with questions that require synthesizing information scattered across many
distant sections of a document, since retrieval is limited to a fixed number
of top-ranked chunks.

Additionally, the weighting between semantic and lexical scores (0.6 and 0.4)
was chosen based on manual tuning on a held-out validation subset rather than
a formal hyperparameter search, and may not generalize optimally to all
document types.

Conclusion

This work demonstrates that combining semantic and lexical retrieval
significantly outperforms either method used in isolation for document
question answering, particularly on precision and recall at moderate cutoff
values such as five. Future work should explore learned combination weights,
reranking models, and evaluation on a broader range of document domains
including legal and medical text.
